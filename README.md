# Student Report Card Automation

An auto-filling report card built in Google Sheets. Select a Roll No. from the dropdown and the whole report card updates instantly.

## Features
- Roll No. dropdown (data validation)
- Student details, marks and percentage fetched from a DATABASE sheet using lookup formulas
- Automatic Pass/Fail per subject
- Final result, overall percentage and grade calculated automatically
- Works for 20 sample students

## Grading Scale
| Percentage | Grade | Remark |
|---|---|---|
| 90%+ | A | Excellent Performance |
| 75%+ | B | Good Performance |
| 60%+ | C | Average Performance |
| 35%+ | D | Need Improvement |

## Tools Used
Google Sheets, Data Validation, VLOOKUP / INDEX-MATCH, IF formulas
